# Введение

avinlab-form — это два небольших пакета для состояния форм:

| Пакет | Для чего |
| --- | --- |
| `@avinlab/form` | Контроллер, не зависящий от фреймворка: подписки и синхронная валидация. |
| `@avinlab/react-form` | Хуки для React 18+ и необязательный помощник для генерируемых контролируемых компонентов. |

## Ментальная модель

Форма — это **один стабильный контроллер** на всё время её жизни. Его `values` и `prevValues` —
**неизменяемые снимки**, которые заменяются при каждом реальном коммите.

- Меняйте значения только через `form.setValue(name, value)` и `form.setValues(values)`.
- Читайте `form.values` императивно и синхронно в обработчиках и командах.
- Изменение формы само по себе **не** перерисовывает React. Реактивность подключается явно:
  используйте `useFormWatch` рядом с тем выводом, которому нужны данные.
- Обновления сравнивают поля верхнего уровня через `Object.is`. No-op сохраняет обе ссылки на
  снимки и не рассылает уведомлений.

## Чего библиотека намеренно не делает

- Нет асинхронной валидации: валидаторы синхронные и выполняются во время коммита.
- Нет глубокого клонирования и заморозки: снимки неглубокие. Вложенные значения заменяйте целиком,
  а не мутируйте.
- Нет собственного провайдера или контекста. Передавайте `form` (или результат валидации) через
  обычные пропсы или свой контекст.

## Проверенный контракт производительности

Документированные гарантии ограничены поведением, покрытым тестами: один цикл уведомлений на
реальный коммит, ни одного уведомления для no-op, одно обновление наблюдателя всей формы на коммит,
один вызов валидации на смонтированный хук валидации за коммит и отсутствие рендера выбранного поля
при изменении чужих полей. Более широких утверждений о скорости, памяти или размере бандла нет.
