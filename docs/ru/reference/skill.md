# Навык для агента

Оба пакета поставляются с навыком (skill) `avinlab-form`, который помогает кодинг-агентам (Cursor,
Claude Code и другим, читающим папки навыков) создавать, менять и ревьюить формы с актуальным API.

## Установка

```sh
npx avinlab-form install-skills
```

Выберите каталог навыков другого агента через `--target`:

```sh
npx avinlab-form install-skills --target .claude/skills
```

Каталог назначения по умолчанию — `.agents/skills`. Установка **отказывается перезаписывать**
существующий навык, поэтому при обновлении сначала удалите старую копию.

Команда доступна, когда `@avinlab/form` или `@avinlab/react-form` — прямая зависимость вашего
проекта.

## Что он покрывает

- Контроллер ядра, снимки и подписки
- Синхронную валидацию в ядре и в React
- Хуки React, синхронизацию, SSR и контракт производительности
- Генерируемые контролируемые компоненты

## Установка вручную

Навык самодостаточен. Скопируйте `node_modules/@avinlab/react-form/skills/avinlab-form` (или тот же
путь в `@avinlab/form`) в каталог навыков вашего проекта.

## Примеры запросов

- «Добавь форму профиля с валидацией на `@avinlab/react-form`.»
- «Почему этот компонент перерисовывается на каждое нажатие клавиши? Сузь наблюдателей.»
- «Оберни наш компонент `Select` через `createFormComponent`.»
